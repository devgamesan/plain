# Command Palette

Complete list of commands available in the command palette, opened with `:`.
Lower-frequency attribute, path-copy, bookmark-edit, external-launch, and reload actions are intentionally available here. Destination navigation is handled by the unified `Go` command, while `~`, `[`, `]`, and `b` remain quick paths.
In transfer mode, the command palette only shows commands that are available for the active transfer pane, including Copy to opposite pane (`c`) and Move to opposite pane (`m`). Keyboard browser-tab operations remain palette-oriented since `Tab` switches panes; the visible tab strip still accepts direct mouse activation, close, and new-tab clicks.
The tab strip is only shown when two or more browser tabs are open.

> Audience: users who know the basics of browsing and need a searchable command reference.

In normal browsing, the path bar also exposes clickable breadcrumb segments and Back/Forward controls. The tab strip exposes tab activation, hover close, and new-tab affordances; the center table exposes Name, Size, and Modified sort headers. These mouse affordances reuse the same actions as the corresponding keyboard and palette commands. Transfer mode keeps its existing keyboard/palette semantics and does not add history buttons to the path bar.

When the query is empty, the palette shows the effective target (`Selection`, `Target`, or `Current folder`) and up to five executable `Suggested` actions. A selected item outside an explicit selection is called out as `not included`. Paste is shown as an operation on the current folder, for example `Paste 2 items here`. The `Navigate`, `File`, `Search`, `View`, `System`, and `Custom actions` names are non-interactive search guidance; typing a query restores the complete command set. Category order and command ranking are deterministic and do not use usage history or telemetry.

Directory History and the Go palette's recent-history source show the most recently visited directories first. Each tab and transfer pane keeps the latest 100 unique directory paths in memory; older entries are discarded automatically.

After a waited terminal editor, foreground terminal, shell command, or `terminal`/`background` custom action completes, zivo refreshes the visible real current directory once when the process cwd or edited file belongs to that directory. The existing cursor, selection, filter, and sort state are reapplied. GUI editors, new terminal windows, default-app launches, config-only overlay completion, Search Workspaces, and archive-only views are not refreshed by this completion hook.

When the latest operation has a next action, the empty `commands` palette puts that action first in the `Suggested` section and fills the remaining slots with context actions, up to five executable items total. Notification priority remains `Undo`, `Open destination`, safe `Retry`, then `Details`. A Details overlay may expose at most one safe recovery action, using `[z] Undo completed items` or `[r] Retry`; `Enter` and `Esc` continue to close the overlay. The StatusBar, Details overlay, and notification `Suggested` item share the same stable action ID and reducer path; existing global keyboard routes keep their current meanings. No new global key is added. A final success notification auto-dismisses five seconds after display; processing, warning/error, and partial-success notifications do not.

`Retry` is limited to a failed paste with no success/skip/overwrite and an original `PasteRequest` whose conflict resolution is unset, a duplicate with no success or applied changes, or archive/zip preparation failure. Each retry runs fresh preparation/preflight and can return to the existing conflict or reconfirmation flow. `Details` shows failure count, target paths, and reasons; when a valid undo entry exists it offers Undo for completed Copy/Move items only. Details closes with `Enter` or `Esc`.

The complete command list is scrollable with the mouse wheel. Keyboard cursor movement (`↑` / `↓` or `Ctrl+j` / `Ctrl+k`) automatically keeps the selected row visible.

Search also matches command keywords and common aliases. Exact label matches rank first, followed by label prefixes, word prefixes, partial matches, and deterministic fuzzy matches. Disabled commands remain searchable and show a concrete reason; pressing Enter reports the same reason without executing the command. Custom actions remain governed by their configured context conditions and are searchable by name.

| Command | Shown when | Behavior / Notes |
| --- | --- | --- |
| `New tab` | Always | Opens a new browser tab initialized from the current directory. |
| `Next tab` | Two or more tabs are open | Activates the next browser tab. |
| `Previous tab` | Two or more tabs are open | Activates the previous browser tab. |
| `Close current tab` | Two or more tabs are open | Closes the active browser tab. The last remaining tab cannot be closed. |
| `Find files` | Always | Opens recursive filename search with `Keyword`, `Target`, `Include extensions`, and `Exclude extensions` fields. Extension values accept comma/space-separated entries such as `py, js` (with an optional leading dot, case-insensitive). Keyword and extension filters are combined with AND; an empty keyword is allowed when an extension filter is set. `Target=files` returns matching files, `Target=all` returns matching files only while extension filters are active, and directory searches require clearing the extension filters. |
| `Grep search` | Always | Opens the shared recursive content search (`ripgrep` / `rg` required on `PATH`). The legacy phrase `search contents` is also a search alias. Choose current directory, selected files/directories, or Search Workspace (available only while browsing one); keyword, filename, include-extension, and exclude-extension filters are available in every scope. Selected directories are searched recursively. |
| `Go` | Always | Press `G` to search Home, bookmarks, recent history, open tabs, and direct paths in one view. Use `@bookmark`, `@history` / `@recent`, `@tab`, or `@home` at the start of the query to limit the source. `b` opens the same view limited to bookmarks. After `/` or `\\` (on Windows), child directories are listed asynchronously while the typed directory remains the first Enter target. `j` and `k` are ordinary query characters; use arrow keys or `Ctrl+j` / `Ctrl+k` to move the selection. |
| `Go back` | Directory history has a previous entry | Moves to the previous directory in history. |
| `Go forward` | Directory history has a forward entry | Moves to the next directory in history. |
| `Go to home directory` | Always | Navigates to the home directory. |
| `Enter folder` | A directory is focused without an explicit selection | Enters the focused directory through the existing directory-navigation action. |
| `Reload directory` | Always | Reloads the current directory. |
| `Toggle transfer mode` / `Close transfer mode` | Always | Switches between the normal three-pane browser and the two-pane transfer layout. |
| `Show preview or contents` / `Back to file list` | Normal browsing below 80 columns with a focused entry | Toggles the single visible narrow-terminal view between the current file list and the details pane. The label follows the current view; `Tab` is the direct shortcut. Search Workspace keeps `Tab` for input-field navigation. |
| `Undo last file operation` | Undo history is not empty | Reverses the most recent undoable rename, paste, duplicate, or trash operation. |
| `Select all` | Current directory has at least one visible entry | Selects every currently visible entry in the current directory, respecting hidden-file visibility and any active filter. |
| `Save results` | Grep search results are shown | Saves the current grep results to `grep_results.txt` in the current directory, including the configured grep preview context lines. Existing files are left unchanged. |
| `Replace text` | Always | Opens one scope-aware replacement palette. Scope is initially Selected files, Current file, or Current directory according to the current selection. Find/Grep result palettes expose `Replace results` (also available with `Ctrl+r`), and Search Workspace exposes `Replace selected results`; these enter the fixed `Search results` scope with the displayed files. The right pane shows a diff preview before confirmation. |
| `Show attributes` | Exactly one target is selected or focused | Opens the read-only attribute dialog for the selected item. |
| `Rename` / `Rename N items` | At least one target is selected or focused (except Search Workspace) | With one target, starts the existing single-item rename input. With two or more, opens a reviewable Old Name / New Name / Status bulk rename overlay. Entering a Base name generates numbered New Name values while preserving each original extension. `Rename items` revalidates every row before applying and rejects collisions, invalid names, disappeared targets, or permission failures. The same flow is available in normal browsing and Transfer mode. |
| `Change permissions` | One or more targets are selected or focused in a real filesystem workspace on Linux, macOS, or WSL | Starts permission input for the selected targets, or the focused target when nothing is selected. Enter a three-digit octal mode such as `755` or `644`. The dialog shows target count/types and that symlinks are skipped and never followed. `Recursive` defaults to `No`; press `Tab` to choose `Yes` and include directory descendants. This command is hidden in search workspaces and native Windows because Windows does not expose POSIX permission bits through `chmod`. |
| `Change owner` | One or more targets are selected or focused in a real filesystem workspace on Linux, macOS, or WSL | Starts owner/group input for the selected targets, or the focused target when nothing is selected. Enter `owner`, `owner:group`, or `:group`. The dialog shows target count/types and that symlinks are skipped and never followed. `Recursive` defaults to `No`; press `Tab` to choose `Yes` and include directory descendants. This command is hidden in search workspaces and native Windows. |
| `Compress as zip` | At least one target is selected or focused | Starts zip compression for the selected items, or the focused item when nothing is selected. The destination input accepts absolute and relative paths resolved from the current directory, defaults to a `.zip` path next to the selected content, and asks for confirmation before overwriting an existing zip file. |
| `Extract archive` | Exactly one supported archive file is selected or focused | Starts archive extraction for `.zip`, `.tar`, `.tar.gz`, or `.tar.bz2`. The destination input accepts absolute and relative paths. Relative paths are resolved from the archive file's parent directory, and the default value is a same-name directory next to the archive. Existing destination paths are confirmed before extraction, and the status bar shows entry-count progress while the extraction runs. |
| `Open` | Exactly one file is selected or focused | Opens the focused file with its OS default application. |
| `Edit with terminal editor` | Exactly one file is selected or focused | Opens the focused file in a terminal editor, using `editor.command` -> `$EDITOR` -> built-in defaults. |
| `Edit with GUI editor` | Exactly one file is selected or focused | Opens the focused file in a configured GUI editor. |
| `Copy path` | At least one target is selected or focused | Copies the selected path list, or the focused path when nothing is selected, to the system clipboard. |
| `Duplicate` | At least one target is selected or focused in a normal filesystem workspace | Copies each selected target, or the focused target when nothing is selected, into its current parent directory. It never overwrites an existing entry; names use `copy`, `copy 2`, `copy 3`, and so on while preserving the extension. Files, directories, and symlinks are supported. Progress, per-target failures, and the successful result are reported. Successful outputs share one Undo entry. |
| `Move to trash` | At least one target is selected or focused | Moves the selected items, or the focused item, to trash (confirmation is enabled by default and can be configured). On Windows this uses the Recycle Bin via `send2trash`. |
| `Permanently delete` | At least one target is selected or focused | Permanently deletes the selected items, or the focused item. Confirmation is always required; multiple targets or directories require the existing two-step `Enter` then `D` confirmation, and the operation cannot be undone. |
| `Open current directory with file manager` | Always | Opens the current directory in the OS file manager. |
| `Open current directory with terminal` | Always | Launches a separate terminal window rooted at zivo's current directory, using `config.toml` templates before built-in fallbacks. Use this for independent or longer-running work. |
| `Run shell command` | Always | Opens a one-line command dialog and runs a short, non-interactive command in the current directory in the background. The dialog shows its cwd; results retain exit code, stdout, and stderr. Press `r` to rerun or `t` to open that cwd in an external terminal. For interactive commands, use foreground shell (`t` from browsing) instead. On Windows, zivo prefers `powershell.exe`, then `pwsh`, then `cmd.exe`, so syntax follows the selected Windows shell rather than POSIX `sh`. |
| Custom actions | Every configured `[[actions.custom]]` entry (entries that do not match `when` or `extensions` are disabled) | Shows reusable named entries from `[[actions.custom]]` in `config.toml`. zivo confirms the expanded command before running it. Use `background` for repeatable non-interactive tasks, `terminal` for interactive tasks, and `terminal_window` for independent work. See [Custom Actions](custom-actions.md). |
| `Bookmark this directory` / `Remove bookmark` | Always | Saves or removes the current directory in `[bookmarks].paths`. The label reflects whether the current directory is already bookmarked. |
| `Show hidden files` / `Hide hidden files` | Always | Toggles hidden-file visibility for the browser panes. The label reflects the current visibility state. |
| `Clear filter` | A name filter is active and has a query | Clears the current-pane filter through the existing filter reducer path. |
| `Edit config` | Always | Opens the settings overlay for startup defaults. You can edit the preferred terminal editor, GUI editor preset, OS-specific external-terminal templates, hidden-file visibility, directory-size visibility, text preview visibility, image preview visibility, image preview mode, PDF preview visibility, Office preview visibility, preview size limit, theme, sorting, default paste-conflict behavior, and delete confirmation. The overlay also explains what the selected setting changes so you do not need to cross-reference the README while browsing options. Theme changes are previewed immediately. |

Empty and fallback panes expose only executable local actions: `Create` for an empty current directory, `Clear filter` for zero matches, `Show hidden files` for a directory whose entries are all hidden, `Open with default app` for unsupported, dependency-missing, error, timeout, resource-limit, or no-text previews, `Show attributes` for permission-denied or other diagnostic-only previews, and `Edit config` for previews disabled in settings. Fallback actions show their direct shortcut when one exists; clicking the inline action is also supported and uses the same reducer flow as the existing command. The fallback action is rejected if the cursor or preview target has changed, and the shared external launcher still supports opening directories with the file manager. The parent pane distinguishes loading, permission denied, no parent directory, and no visible items, while cached entries remain visible during refresh.
| `Create` | Always | Opens one flow for files and directories. Choose Type explicitly, enter a relative path (including missing subdirectories), and verify the parent directory and final target preview before applying. `n` starts with File and `N` starts with Directory selected. |

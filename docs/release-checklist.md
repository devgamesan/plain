## 共通項目

### README画像

- [ ] README の GIF は現行のキー表示・ペイン表示と一致し、カラーかつ高解像度で文字が読みやすいこと
- [ ] `rsvg-convert`（librsvg）と開発依存の Pillow が利用できること
- [ ] `uv run python scripts/capture_readme_gifs.py` で3枚を再生成できること
- [ ] 生成物のサイズが3枚とも FullHD（1920×1080）であること
- [ ] 操作例がプロジェクトの閲覧・READMEプレビュー・READMEのdocsへのコピーを示すこと

### 基本操作

- [ ] アプリケーションが正常に起動すること（`zivo` コマンド）
- [ ] ヘルプバーが表示され、主要なキーバインドが確認できること
- [ ] カーソルキー（j/k/↑/↓）でカーソルが移動すること
- [ ] PageUp/PageDown でページ単位の移動ができること
- [ ] Home/End で先頭/末尾に移動できること
- [ ] h/← キーで親ディレクトリに戻れること
- [ ] l/→/Enter キーでディレクトリに入れること
- [ ] Enter キーでファイルを開けること
- [ ] q キーでアプリケーションが終了すること
- [ ] コマンドパレットが開くこと（: キー）
- [ ] Esc キーで選択/フィルターが解除されること

### ファイル操作

#### コピー＆ペースト
- [ ] Space キーでファイル/ディレクトリが選択できること
- [ ] Shift+↑/↓ で範囲選択ができること
- [ ] a キーで表示されている全項目が選択できること
- [ ] c キーで選択項目がコピーされること
- [ ] x キーで選択項目がカットされること
- [ ] v キーでペーストできること
- [ ] ペースト時に名前衝突ダイアログが表示されること
- [ ] 名前衝突時に「上書き/スキップ/リネーム/キャンセル」が選択できること

#### 削除操作
- [ ] d キーでゴミ箱へ移動できること
- [ ] ゴミ箱移動前に確認ダイアログが表示されること（デフォルト）
- [ ] D キーまたは Shift+Delete で完全削除できること
- [ ] 完全削除前に確認ダイアログが表示されること
- [ ] 完全削除確認に復元不可、対象件数、合計サイズ、最大3件の代表名が表示されること
- [ ] 複数対象またはディレクトリの完全削除で Enter → D の二段階確認が必要なこと
- [ ] i/C/B/M/O/T/H/R が通常・Transfer・Search Workspaceで直接実行されないこと

#### リネーム＆作成
- [ ] r キーで単一項目のリネームができること
- [ ] 2 件以上を選択して r キーまたはコマンドパレットから `Rename N items` を開けること
- [ ] 一括リネームで Base name、Old/New/Status、変更・未変更・エラー件数、`enter apply | esc cancel` のヒントが表示されること
- [ ] 空名・区切り文字・予約名・既存衝突・循環（a→b、b→a）が正しく検証・実行されること
- [ ] 一括リネーム失敗時に元名へロールバックされ、Undo 履歴が作成されないこと
- [ ] 一括リネーム成功時に選択・カーソルが新しいパスへ移り、1 回の Undo で全件を戻せること
- [ ] n キーでファイルを作成できること
- [ ] N キーでディレクトリを作成できること
- [ ] リネーム/作成時に同名ファイルが存在する場合、適切なエラーが表示されること

#### Permission / Owner 変更
- [ ] コマンドパレットに「Change permissions」と「Change owner」が各 1 件ずつ表示されること
- [ ] 両ダイアログで対象数・種別・symlink を辿らない方針が実行前に表示されること
- [ ] `Recursive` の既定値が `No` で、Tab で切り替えられること
- [ ] `Recursive: Yes` ではディレクトリ配下に適用され、symlink とそのリンク先は変更されないこと
- [ ] Search Workspace と native Windows ではこれらのコマンドが表示されないこと

#### Undo
- [ ] z キーで直前のファイル操作（リネーム/ペースト/ゴミ箱移動）が取り消せること
- [ ] 複数回 z キーを押すと、操作履歴を順に取り消せること
- [ ] Undo 履歴が空の場合、適切なメッセージが表示されること
- [ ] コマンドパレットから「Undo last file operation」が実行できること

#### アーカイブ操作
- [ ] 単一の .zip/.tar/.tar.gz/.tar.bz2 ファイルを選択し、「Extract archive」で展開できること
- [ ] 展開先の指定ができること
- [ ] 展開先が既存の場合、確認ダイアログが表示されること
- [ ] 複数項目を選択し、「Compress as zip」で圧縮できること
- [ ] 圧縮先の指定ができること
- [ ] 圧縮先が既存の場合、確認ダイアログが表示されること

#### 長時間ファイル操作の進捗とキャンセル
- [ ] Copy / Move / Compress / Extract / Replace 実行中に操作名、件数、割合またはspinner、現在対象がStatusBarに表示されること
- [ ] 総数が不明な操作で不正確なpercentageを表示せず、spinnerが表示されること
- [ ] 安全にキャンセルできる操作だけ `Cancel` と `Esc cancel` が表示されること
- [ ] Cancel要求後に `Cancel requested; finishing current item` が表示され、Cancelを重複実行できないこと
- [ ] 現在の対象を完了してから停止し、workerの強制停止を行わないこと
- [ ] 成功、skip、failure、未処理件数と対象pathが通知・Detailsで確認できること
- [ ] Copy / Move の完了済み対象だけがUndo範囲として表示されること
- [ ] Detailsに有効なUndoまたは安全なRetryがある場合だけ復旧Actionが最大1件表示され、`z` / `r`で実行できること
- [ ] Detailsの`Enter` / `Esc`が従来どおり閉じる操作であること
- [ ] Compressキャンセル時に既存destinationが維持され、一時アーカイブが残らないこと
- [ ] Extract / Replaceキャンセル時に書き込み途中の一時ファイルが残らないこと
- [ ] 処理中に別のファイル変更操作を開始できず、進行中の操作名が表示されること
- [ ] 処理中も通常ブラウズ、ディレクトリ移動、ファイル検索、プレビュー、属性表示を継続できること
- [ ] 処理中の別のファイル変更、Undo、エディタ・シェル起動、変更を伴うカスタムアクションが進行中の操作名付きで拒否されること
- [ ] 完了後も現在の表示パスを維持し、影響を受けた可視ペインだけが更新されること
- [ ] 処理中の終了要求が協調キャンセルと後始末の完了を待ってからアプリケーションを終了すること
- [ ] 古いoperation IDのprogressが現在のStatusBarを上書きしないこと

### プレビュー機能

#### テキストプレビュー
- [ ] テキストファイル（.txt, .py, .md など）を選択すると、右ペインにプレビューが表示されること
- [ ] プレビューがシンタックスハイライトされていること
- [ ] [/] キーでプレビューがスクロールできること
- [ ] 大きなファイルの場合、設定された上限までプレビューが表示されること
- [ ] 設定で `enable_text_preview = false` の場合、プレビューが無効になること
- [ ] converter の timeout / stdout / stderr 上限があり、上限到達時もブラウジングを継続できること
- [ ] 安全な部分出力には `Preview limited` 相当の状態が示されること

#### 画像プレビュー（chafa がある場合）
- [ ] 画像ファイル（.png, .jpg, .gif など）を選択すると、右ペインにプレビューが表示されること
- [ ] chafa による文字アートが正しく表示されること
- [ ] 設定で `enable_image_preview = false` の場合、プレビューが無効になること
- [ ] chafa がない場合、「install `chafa` for image preview」メッセージが表示されること
- [ ] timeout または出力上限時に壊れた途中画像を表示せず、metadata fallback になること

#### PDF プレビュー（pdftotext がある場合）
- [ ] PDF ファイルを選択すると、右ペインにテキストプレビューが表示されること
- [ ] 設定で `enable_pdf_preview = false` の場合、プレビューが無効になること
- [ ] pdftotext がない場合、適切なメッセージが表示されること

#### Office ドキュメントプレビュー（pandoc がある場合）
- [ ] .docx/.xlsx/.pptx ファイルを選択すると、右ペインにテキストプレビューが表示されること
- [ ] 設定で `enable_office_preview = false` の場合、プレビューが無効になること
- [ ] pandoc がない場合、適切なメッセージが表示されること
- [ ] Pandoc 実行前に OOXML の entry 数・展開量・圧縮率上限が検査されること
- [ ] timeout / resource limit が dependency missing や unsupported と混同されないこと
- [ ] cursor を連続移動したとき、古い preview の converter が cancel され結果が表示されないこと

### 検索機能

#### ファイル検索（ripgrep が必要）
- [ ] f キーまたは「Find files」でファイル検索パレットが開くこと
- [ ] 検索文字列を入力すると、結果がリアルタイムにフィルタリングされること
- [ ] 検索結果から Enter キーでファイルにジャンプできること
- [ ] 検索結果で Ctrl+o キーで GUI エディタを開けること
- [ ] 検索結果でファイルのプレビューが表示されること
- [ ] ripgrep がない場合、適切なエラーメッセージが表示されること

#### grep 検索（ripgrep が必要）
- [ ] g キーまたは「Grep search」で grep 検索パレットが開くこと
- [ ] 検索文字列を入力すると、マッチした行が表示されること
- [ ] ファイル名フィルター（Filename）で結果を絞り込めること
- [ ] 拡張子フィルター（Include/Exclude extensions）で結果を絞り込めること
- [ ] 検索結果から Enter キーでファイルにジャンプできること
- [ ] 検索結果で Ctrl+e キーでエディタを開けること
- [ ] 検索結果で Ctrl+o キーで GUI エディタの該当箇所を開けること
- [ ] 検索結果でコンテキストプレビューが表示されること

#### 選択ファイルでの grep 検索
- [ ] ファイルを選択状態で「Grep in selected files」が使えること
- [ ] 選択ファイル内のみが検索対象になること

### ナビゲーション機能

- [ ] 1-9, 0 キーで対応するタブに切り替わること

- [ ] ] キーまたは「Go forward」で次のディレクトリに進めること

#### ブックマーク

#### パス指定
- [ ] G キーまたは「Go」でパス指定と移動先検索が開くこと
- [ ] パスを入力すると、補完候補が表示されること
- [ ] パス区切り（POSIXの`/`、Windowsの`/`または`\\`）入力直後に直下の子ディレクトリ候補が表示され、入力中のディレクトリが先頭のEnter対象として残ること
- [ ] 区切り直後のloading・0件・権限エラー・stale resultが直接移動候補を壊さず、状態を認識できること
- [ ] Tab キーでパス補完ができること
- [ ] `@bookmark`、`@history`、`@tab`、`@home` で候補sourceを絞れること
- [ ] Go画面では `j` / `k` を検索文字として入力できること
- [ ] ~ キーまたは「Go to home directory」でホームディレクトリに移動できること
- [ ] 絶対パスと相対パスの両方が使えること
- [ ] 5,000 sibling directories で Go 入力が UI を同期的に塞がず、loading/0件/truncated 表示と stale result 排除が機能すること

## Ubuntu 固有項目

### クリップボード操作
- [ ] X11 環境で xclip または xsel によるクリップボード操作ができること
- [ ] Wayland 環境で wl-clipboard によるクリップボード操作ができること
- [ ] 「Copy path」でパスがクリップボードにコピーされること
- [ ] ペースト時にクリップボードから正しく読み取れること

### ターミナルエミュレータ
- [ ] gnome-terminal で起動できること
- [ ] konsole で起動できること
